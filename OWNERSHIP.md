# Skill ownership

The canonical repository for the skills in this directory is
[svd-ai-lab/sim-skills](https://github.com/svd-ai-lab/sim-skills).
Each top-level skill directory is its repository-relative source path.
Maintained skill text and scripts are licensed under MIT; each skill includes a
copy of the license so it can be redistributed independently.

The `pdf`, `docx`, and `xlsx` workflows and PDF renderer are original SVD AI Lab
implementations. They use publicly documented library APIs. Libraries and
external applications retain their own licenses and are installed separately.
Commercial CAD and solver software and licenses are supplied by the user.
